## 修复前的测试结论

最严重的问题是 **Windows 编辑器在 ACT3 跟随潜水员前往港口期间退出**。本次三轮开启正常音频的游程均出现原生音频线程崩溃，包括一次原速护送、游客原地停步的复测。仅关闭视频音轨的对照轮走完了全部流程。该对照只跑了一轮，不能据此锁定视频素材、引擎或某个点击为根因。

针对交互行为定义了 **34 个场景检查点和 12 个命令/状态用例**。在能跑到交接的对照轮，34 项中 32 项符合预期，2 项分别揭示 ACT3 对话按钮的反馈问题、ACT2 装回记录的归因问题。12 项命令/状态用例均通过。崩溃作为整轮稳定性问题单独报告。另有一条没有造成游客可见错误的内部诊断。重复跑同一用例只计算一次。

## 测试对象与判定

测试对象为 `integration` 分支当前工作树，基线提交 `174de8ff9e1a`，包含本地尚未提交的集成修改。团结引擎 1.6.13、XRI 3.1.2，完整场景 `Assets/Scenes/BasicScene.unity` 的 SHA-256 为 `D7B5CEB0050C4A3FFF3CEB190744B362DF4A7B7DCE8C165C74DBEA31410414E4`。

测试设计以游客做错一步后能否自行继续为核心。先记录阶段、任务计数、可见文案或按钮状态，再提交一个错误输入。等候超过正常的反馈或凝视时间，复查阶段、实际物体、事件和界面，随后用合法输入验证能否继续。需要计数的任务同时对照“仅拾起”“已放置”和“阶段完成”，避免用一个数字推断整段体验的结果。

| 测试手法 | 输入与观察 |
|---|---|
| 次序与位置 | 提前选右键、先到错误展台、未观察就尝试装回、离绳操作。观察按钮、引导和阶段有无误推进。 |
| 未完成与取消 | 凝视未满就移开、持球不放、持盔靠近头部但继续握住、只携带垃圾。观察提示、持有状态和计数。 |
| 重复与混合 | 持续凝视、同目标的手柄与凝视输入、重复命令、行程中再次按键。核对一次操作是否造成两次效果。 |
| 退出与中断 | 跟丢潜水员、播放时离开展台、未清完就上浮、暂停或换人后旧事件晚到。回到现场或恢复后检查是否可继续。 |
| 权限与结束 | 展览模式下游客尝试工作人员命令，核对清理完成、出水和落到平台这几个时刻。 |

**判定标准**　合法的暂停、等待或拒绝可以算通过，前提是阶段与任务状态正确，而且仍有可行的恢复操作。若状态正确但文字或记录误导，单列反馈或日志缺陷。测试环境缺少必要前提的用例标为未验证，不计入通过。

这一组直接执行生产代码中的命令分发器、会话状态机、凝视计时和训练球逻辑。命令回执是工作人员接口的输出，不代表游客头显出现同名提示。

| P01、P02 | 展览模式下由游客发送 Start、Skip，应拒绝 | 均返回 `StaffOnly`。待机时仍在 Briefing，工作人员随后 Start 成功。在 ACT1 时任务仍为 Active，真正佩戴后才进 ACT2。 |
| P03 | 工作人员重发同一条 Skip，只应跳过一次 | 两次均取得 `Applied` 回执，执行次数为 1，ACT1 标记 Skipped，ACT2 可继续完成。 |
| P04、P05 | 暂停后投递旧 Skip、任务完成和第二次 Pause | 旧版本 Skip 返回 `StaleState`，暂停时任务完成返回 false，第二次 Pause 返回 `InvalidState`。Resume 后原任务可继续。 |
| P06、P07 | Back 后投递上一次尝试的结果，或换人后投递上一位游客的命令与回调 | 旧结果均拒绝。Back 保留原会话与先前的 Skipped。Reset 后新一轮会话 ID 改变。新尝试的完成事件均能推进。 |
| P08、P09 | 在 3/9 时申请退出、自由探索、报告返岸，或上报重复、倒退、超过总数和更换总数的进度 | 全部拒绝，仍是 3/9、海底清理。随后合法 4/9 被接受。 |
| P10 | 2/9 时由工作人员连续发两条独立的 Skip，希望直接结束 | 第一条 `Applied`，第二条 `InvalidState`。计数保持 2/9，清理结果记 Skipped。随后有效的平台返回事件才能进入结束阶段。 |
| P11、P12 | 同目标手柄和凝视同时提交。凝视持球时收到手柄释放或取消选择 | 同目标只接受第一次，移开 0.4 秒后可重新选择。错误来源的放球被忽略，取消后教程仍待完成，随后用同一输入方式抓放即可完成。 |

### 复测方式

1. 打开 `BasicScene`，保持展览模式及正常音频，开启 Accessible Mode，由工作人员 Start。每一轮记下会话 ID。使用固定复现顺序时，先完成该行要求的前置步骤。
2. 在 Briefing 先尝试右键，再短看左键并移开。正常完成左右键，拿球后等待。放球后继续盯着同一位置。对照步骤数、可见按钮和是否进入 ACT1。
3. ACT1 先走到 ACT2，再返回正确展台。手持头盔靠近头部但不松开，再移回展台松开。视频用历史展台的 `helmet_history.mp4` 复测，在范围外点击、进入范围播放、播放中离开、再返回。
4. ACT2 对第一件零件依次尝试提前装回、重复拆下、观察后使用展台的“散落零件归位”。再次拆下同一件，观察并正常装回。对照学习进度和两次 `PartRestored` 的来源。独立测试第二个按钮时，先移开视线并间隔至少 0.4 秒，避开系统的 0.35 秒跨输入防重复时间。
5. ACT3 在潜水员带路后留在原地，待其停等再追上，并尝试展台重置。ACT4 在绳外和绳旁分别操作。空手看篮、持物不投、回收一件后提前上浮，再回潜继续。分别记录入水、清理到 9/9、上浮途中和抵达平台时的结束面板。
6. 到达结束面板后尝试暂停、误选和重复选择。接口层用首次命令的 ID、会话 ID、版本号重发同一命令，再分别替换成过期会话和过期版本，核对拒绝原因并发送下一条合法命令。
