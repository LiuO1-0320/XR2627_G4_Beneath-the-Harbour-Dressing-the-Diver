# Experience local sound beds

MuseumGentleLoop.wav is a new original 64-second stereo musical underscore, generated by Tests/generate-experience-museum-music.py. It uses slow soft synthesized chords and sparse felt-like notes, without percussion or external samples. Peak -15.0 dBFS, RMS -27.5 dBFS before runtime gain. It is assigned to DefaultAudioMap.museumMusic for Briefing and ACT1–3. Existing harbour, underwater and feedback files are unchanged.

Background selection now follows visitor position: museum music away from the water, harbour ambience near the shoreline, and underwater ambience only with the head physically submerged. Default shoreline blend spans 14 m to 5 m; AudioDirector allows an explicit harbour collider and distance settings. Stage changes, NPC escort and helmet fitting do not select the background. Helmet feedback and approved inside narration remain action-triggered. Pause/Reset still govern playback. See Audio-System.md for current tuning and acceptance steps.

HarbourSoftLoop.wav and UnderwaterSoftLoop.wav are original deterministic synthesized ambience, generated by Tests/generate-experience-audio.py. They are artistic exhibition sound beds, not archival recordings. InteractionSoft.wav and SuccessSoft.wav are original synthesized short feedback tones.

All files are local PCM WAV, 44.1 kHz, 16 bit. Loops are 32 seconds stereo; feedback clips are mono. Source peaks are below -13 dBFS. The runtime applies additional gain reduction and fades. No external samples, services or runtime network access are used.

ACT1–3 narration in the adjacent Narration folder is supplied by the project team and remains unmodified. Other narration slots require approved M2/M5 recordings. Headset listening and in-editor audio import validation remain required before exhibition use.
